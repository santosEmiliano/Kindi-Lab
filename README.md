# Kindi Lab

Client-side web app that encrypts and decrypts a sentence with **Caesar** or
**Atbash** over a configurable ASCII/Unicode character set, and on decryption
figures out **automatically** which method was used and (for Caesar) the shift,
with no human in the loop, via statistical analysis of Spanish text.

Named after Abu Yusuf al-Kindi, who in Baghdad (~850 CE) wrote the first known
treatise on cryptanalysis by frequency analysis.

Individual project for *Seguridad en Sistemas de Cómputo* (UAA).

## Status
